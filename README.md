# sales-profitability-analysis

Built an end-to-end Profit & Loss (P&L) reporting solution in Excel using Power Query, Power Pivot, and DAX. Developed a star-schema data model and created dynamic reports for sales, profitability, customer, product, and regional performance analysis.

### Tools Used
- Excel
- Power Query
- Power Pivot
- DAX (basic)
- Pivot Tables

### Key Metrics
Revenue, COGS, Gross Profit, Gross Margin %, EBIT, Net Profit, Net Margin %, YoY Growth, YTD Revenue, and QTD Revenue.

### Key Insights
- Generated **24.91M Revenue** and **10.46M Gross Profit**
- Maintained a stable **42% Gross Margin**
- Q2 was the strongest performing quarter
- Mountain bike products delivered the highest profitability
- Several customers achieved **400%+ YoY Growth**
